# Drone-digital-Twin- 
Description: I built a digital twin of a drone for this project using Python. I selected a drone for building a digital twin because I felt like it would give me a very cool outcome and also just be fun to create. 

How it Works: This program is a drone simulated by a Python class and it maintains information such as the drone's battery, speed, altitude, and flying status.

How to run the file- Open the python file. Run the program and it will display the drone's actions. 

what I learned- This made me better understand how classes and methods work in python.
